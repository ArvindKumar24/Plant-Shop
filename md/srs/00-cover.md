### Project Deliverables Summary

- **Functional E-Commerce Website** — browse, search, filter, and purchase indoor & outdoor plants.
- **Customer Account System** — registration, login, cart, checkout, and order tracking.
- **Admin Dashboard** — product management, order management, and UPI payment configuration.
- **REST API Backend** — pure Python server exposing JSON endpoints.
- **Relational Database** — MySQL schema with 5 normalized tables and seed data.
- **Complete Documentation** — the SRS you are reading now.
